Report Questions

1. What is CSS?
CSS stands for Cascading Style Sheets. It is the language used to describe how HTML elements are displayed, such as colors, fonts, spacing, and layout.

2. Why is CSS used with HTML?
HTML provides the structure and content of a webpage, but on its own it looks plain. CSS is used with HTML to separate content from presentation, so the look of a page can be designed and changed from one external file without editing the HTML.

3. What is a CSS selector?
A selector is the part of a CSS rule before the opening brace { }. It points to the HTML element or elements that the style should be applied to. For example, in "p { color: blue; }", the selector is "p".

4. What is the difference between an element selector and a class selector?
An element selector targets every element with that tag name, so "p" styles all paragraphs on the page. A class selector targets only elements that have a specific class attribute, such as ".highlight", and the same class can be reused on many different elements.

5. What is the difference between a class selector and an ID selector?
A class is written with a dot (.) and can be used on any number of elements on the page. An ID is written with a hash (#) and must be unique, so only one element on the page can have that ID. ID selectors also have higher specificity than class selectors.

6. Why is the universal selector represented by *?
The asterisk (*) is a wildcard symbol that matches everything, so in CSS it means "select every element on the page". It is commonly used to reset default margins and padding so all elements start from the same base.

7. Which selector did you find easiest to use and why?
I found the class selector easiest to use because you simply add a class name to any element and then reuse it wherever you want. It is easy to read and keeps the CSS organized instead of writing a separate rule for every element.

8. Mention one problem you faced while completing the task and how you solved it.
At first my styling did not appear because in the link tag I wrote "styles.css" instead of "style.css", which is the actual file name, so the browser could not find the stylesheet. I checked the file name in the project folder, corrected the link, and refreshed the page, and then the CSS worked.
